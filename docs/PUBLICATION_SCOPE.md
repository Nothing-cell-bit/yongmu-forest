# 本次公开范围

本仓库由独立导出目录生成，没有上传开发电脑上的整个工作区，也没有继承其他本地 Git 历史。首次导入为代码快照；随后加入有来源记录的439张PNG图片。

## 原样复制

- 运行包中的 Python 文件。
- 原有 `tools/` 与 `tests/` 下的 Python 文件。
- 一份小型世界生成测试基线 JSON。
- 原项目代码许可声明和 LGPL 全文。

复制文件的 SHA-256 见 `SOURCE_SNAPSHOT.json`。导出后再次读取源文件核对，避免快照过程中发生无记录变化。

生成目录索引（如 `ruin_catalog_data.py`）保留为运行代码所需的数据引用；索引指向的实际结构文件不包含在内。

## 本次新编写

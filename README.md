# 永暮之森 · 代码与接力计划

面向网易《我的世界》的非官方模组适配研究。这个仓库公开现阶段的开发代码、测试与接力说明，希望后续开发者能够继续研究、整理和完善。

**当前状态：开发中的代码快照。此次 PC / PE 提交未通过审核；本仓库不提供可直接安装的模组包。**

此前一个月的工作涉及森林维度、传送门、地图、遗迹、Boss 战斗与客户端 UI。现在将能够独立整理的代码留下，并逐步探索新的模型、设定与战斗设计。

## 这个仓库有什么

| 目录 | 内容 |
| --- | --- |
| `TwilightBossSliceB/TwilightBossSlice/` | 运行逻辑、服务端/客户端适配、地图与 UI 控制代码、生成目录索引 |
| `tools/` | 原有 Python 构建、检查、转换和开发工具；多数资源工具需要外部合法资源 |
| `tests/` | 原有逻辑与资源契约测试；公开测试入口只运行不依赖缺失资源的部分 |
| `docs/` | 本快照的运行、范围、状态与接力文档 |
| `SOURCE_SNAPSHOT.json` | 从工作目录提取的文件列表、大小及 SHA-256，供核对来源 |

本次未包含：游戏 SDK、Java JAR、模型/贴图/音效/动画等游戏资产、结构二进制、存档、资源包清单、录屏、聊天记录、运行日志、缓存、账户配置以及本机部署脚本。部分 Python 工具能够生成或转换资源，其代码的公开不代表工具输入或输出的第三方素材获得了重新授权。

因此，GitHub 的 **Download ZIP 是源代码下载**，不能直接作为网易组件导入游戏。

## 快速开始：运行公开逻辑测试

使用 Python **3.11**，无需安装第三方包：

```bash
git clone https://github.com/Nothing-cell-bit/yongmu-forest.git
cd yongmu-forest
python tools/run_public_tests.py
```

这会检查传送门、娜迦、巫妖、九头蛇、魔法地图、迷宫地图、权杖与部分进度逻辑。测试通过不代表缺失的资源齐全、平台审核通过或真实客户端已经完成验证。

NetEase 运行适配层保留目标 SDK 所用的 Python 2 风格代码；本机 Python 3.11 用于离线逻辑测试和开发工具。不要直接使用 CPython 启动 `modMain.py`、`serverSystem.py` 或 `clientSystem.py`。详见 [开发与运行](docs/DEVELOPMENT.md)。
